# Description
this is a modular gel/filter holder for Godox TT520 flash (same as many cheap external flash units). The gel sheets is sized 60x75mm. It uses 8x 6x1.5mm disc magnets (same size as Gridfinity magnets) to hold the gel in place.

It is designed as a clamp for the front of the flash, it requires a M3x10 screw and a 5mm long heat insert.

## Print settings:
0.4mm nozzle recommended. Tolerance 0.1mm, magnet is a press fit.
