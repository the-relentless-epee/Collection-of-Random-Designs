# Super Slim Wallet
this is a very slim wallet, designed to be barely thicker than the cards that it holds.

Printed in 2 halves, glued together.
Compliant spring keeps cards in. Clicks when the cards are in place, fun to fidget with.

Springs dimensions are designed for the stiffness of PLA+. PETG might be too soft. ABS is fine.
Print with 0.4mm nozzle, Arachne wall generator.
